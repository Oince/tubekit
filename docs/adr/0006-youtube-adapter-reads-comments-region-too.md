# 댓글 패널만 쓰는 YouTube 화면 해석도 core 어댑터에 두고, 기다림과 기억은 기능에 남긴다

ADR 0005의 YouTube 어댑터(`src/core/youtube.js`)를 넓힌다. 댓글 패널만 쓰는 판정도 YouTube 화면을 해석하는 것이면 어댑터에 둔다. YouTube의 댓글 묶음과 관련 동영상 목록이 어디 있는지, 댓글이 다 나타났는지, 업로더가 댓글을 껐다는 표시가 떴는지, 실시간 방송 옆에 댓글이 비어 있는 모습인지가 여기에 든다. 이렇게 하면 YouTube가 화면 구조를 바꿨을 때 고칠 곳이 어댑터 하나로 정해진다. 그 대가로 공용 모듈에 한 기능만 쓰는 판정이 늘어난다. 이 정도는 AGENTS.md가 모듈 단위로 따지는 core 규칙 안에 든다.

어댑터는 ADR 0005대로 상태를 기억하지 않으므로, 지금 화면만 보고 답할 수 있는 판정만 맡는다. 시간과 기억이 드는 정책은 기능에 남는다. 실시간 방송이면 3초를 기다려 확정하는 것, 20초 안에 나타나지 않으면 실패로 보는 것, 한 번 꺼짐으로 판정했다는 기억, 노드를 가져오고 돌려놓는 일이 그렇다. 그래서 **댓글이 꺼진 영상** 판정은 두 곳에 나뉜다. 무엇이 보이면 꺼짐 후보인지는 어댑터가 정하고, 얼마나 기다려 확정할지는 댓글 패널의 로더가 정한다.

## Consequences

- 2열 화면 판정과 YouTube 패널 판정도 같은 성격이라 어댑터로 옮겼다(ADR 0007). 이제 댓글 패널에 남은 YouTube 화면 해석은 없다.
- 0.8.5에서 댓글 꺼짐·로딩 판정과 기다림 정책(3초·20초 대기, 실패 안내, 자동 전환)을 없애, 어댑터의 판정(`commentsOffCandidate`, `commentsHaveLoaded`)과 로더의 상태 머신을 함께 지웠다. 댓글 패널은 댓글 자리를 가져오고 YouTube가 갈아 끼우면 따라가는 일만 한다.
