# 댓글 패널의 탭 영역에는 렌더링 격리(`contain`)를 걸지 않는다

v0.3.10에서 iPad 터치 스크롤 끊김을 줄이려고 **댓글 패널**의 탭 영역에 `contain: content`를 걸었다. 그런데 이 격리가 화면 기준으로 띄우는 YouTube 메뉴까지 패널 안에 가뒀다. 댓글 `정렬 기준` 메뉴는 버튼 오른쪽 끝에 맞춰 열리는데, 패널이 좁고 버튼이 왼쪽에 있을수록 메뉴 왼쪽이 패널 밖으로 나가 `인기순`·`최신순` 글자까지 잘렸다. 그래서 v0.6.9에서 격리를 뺐다. 성능을 다시 손볼 때도 탭 영역이나 그 조상에 `contain`(`content`, `paint`, `layout`, `strict`)을 걸지 않는다. 격리를 걸면 패널 밖으로 나와야 하는 메뉴와 팝업이 잘린다.
