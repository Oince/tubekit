# YouTube 패널 탭 줄에는 "모두 닫기"를 두지 않는다

v0.8.0에서 **YouTube 패널 탭** 줄 오른쪽 끝에 "모두 닫기"를 넣었다. 이 버튼은 각 패널의 닫기(X)를 스크립트가 대신 눌러 주는 방식이었다. 그런데 YouTube는 화면을 터치한 직후 잠깐 동안, 터치한 곳이 아닌 곳의 클릭을 막는다. 그래서 iPad에서 "모두 닫기"를 터치하면 일부 패널만 닫혔다. v0.8.1에서는 탭 줄의 터치를 YouTube에 알리지 않게 해서 이 문제를 피했다. 하지만 그 때문에 **동영상 정보** 패널을 터치한 직후(약 2.5초 안)에는 탭을 터치해도 탭이 바뀌지 않았다. 결국 v0.8.2에서 버튼과 터치를 숨기던 처리를 모두 뺐다. 패널은 각 패널의 닫기(X)로 닫는다. YouTube 버튼을 스크립트가 대신 눌러 주는 기능은 터치 화면에서 확실하게 동작하지 않으니 다시 넣지 않는다.
