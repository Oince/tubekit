# Tubekit

YouTube를 쓰면서 불편했던 점을 고치는 개인용 유저스크립트입니다.

설치·업데이트 주소:

```text
https://raw.githubusercontent.com/Oince/tubekit/main/tubekit.user.js
```

## 기능

### 오른쪽 댓글 패널

플레이어와 영상 정보의 배치는 그대로 두고, 오른쪽 열을 `댓글 | 관련 동영상` 탭으로 바꿉니다.

- 2열 화면에서는 오른쪽에 `댓글 | 관련 동영상` 탭이 나타납니다.
- 영상에 들어가면 댓글 탭이 먼저 열립니다.
- 두 탭은 같은 영상에서 전환하는 동안 각각의 스크롤 위치를 유지합니다.
- 탭에 키보드 포커스를 둔 상태에서 좌우 방향키로 전환하고, Home/End로 첫 번째/마지막 탭을 선택할 수 있습니다.
- 별도의 전환 버튼은 없고 2열 화면에서는 항상 자동으로 적용됩니다.
- 극장 모드, 미니플레이어, 좁은 단일 열 화면처럼 2열 화면이 아니게 되면 YouTube의 원래 레이아웃으로 돌아갑니다. 같은 영상에서 다시 2열 화면이 되면 보던 탭이 다시 열립니다.
- 전체화면을 켜면 그동안 댓글 패널을 숨겨 둡니다. 전체화면을 끄면 보던 탭과 스크롤 위치로 돌아옵니다. 그 사이 다른 영상으로 넘어갔거나 끈 뒤의 화면이 2열 화면이 아니면 위처럼 원래 레이아웃으로 돌아갑니다.
- 실시간 채팅(다시보기 포함), 챕터, 스크립트처럼 YouTube가 오른쪽 열에 패널을 펼치면 그동안 댓글 패널을 숨깁니다. 댓글과 관련 동영상도 함께 숨으며, 패널을 닫으면 보던 탭과 스크롤 위치로 돌아옵니다.
- 업로더가 댓글을 끈 영상이나 진행 중인 실시간 방송처럼 댓글이 꺼진 영상에서는 알림을 띄우고 관련 동영상 탭으로 바꿉니다. 방송이 끝난 다시보기는 댓글이 있으므로 채팅을 닫으면 댓글 탭이 보입니다.
- 적용 주소는 `https://www.youtube.com/watch?v=...`입니다. YouTube가 플레이어와 오른쪽 열을 나란히 놓은 화면(2열 화면)이면 동작합니다. 픽셀 기준을 따로 두지 않고 YouTube의 배치를 그대로 따르며, YouTube는 보통 스크롤바를 뺀 페이지 너비가 **1000 CSS px 이상**일 때 2열로 바꿉니다. 그래서 스크롤바가 자리를 차지하는 환경에서는 창 너비 약 1015px부터, 오버레이 스크롤바 환경에서는 1000px부터 적용됩니다. 모니터 해상도와 다르며 브라우저 확대/축소의 영향을 받습니다.
- `m.youtube.com`(모바일 웹), YouTube 앱, 쇼츠 화면에는 적용되지 않습니다.

### 쇼츠를 영상 화면에서 열기

쇼츠 영상을 쇼츠 화면(`/shorts/...`) 대신 영상 화면(`/watch?v=...`)에서 엽니다. 데스크톱(`www.youtube.com`)과 모바일 웹(`m.youtube.com`) 모두에 적용됩니다.

- 쇼츠 화면 주소를 직접 열거나 새 탭에서 열면 바로 영상 화면 주소로 바꿔 엽니다. 시작 시간 등 주소의 다른 값은 유지합니다.
- YouTube 안에서 쇼츠 영상을 클릭하면 새로고침 없이 영상 화면으로 이동합니다. 뒤로 가기를 누르면 원래 페이지로 돌아갑니다.
- 영상 화면이므로 2열 화면에서는 오른쪽 댓글 패널도 적용됩니다.
- 왼쪽 메뉴나 모바일 하단 탭의 `Shorts`처럼 특정 영상 없이 쇼츠 화면에 들어가도 YouTube가 고른 첫 영상을 영상 화면에서 엽니다.

### 최고 화질 자동 선택

- 데스크톱(`www.youtube.com`), 모바일 웹(`m.youtube.com`), 다른 사이트에 넣은 영상(`youtube.com/embed`, `youtube-nocookie.com/embed`)에 적용됩니다.
- 영상이 바뀐 뒤 처음 재생될 때 한 번 바꿉니다. 광고가 끝나 본 영상이 시작될 때도 이때로 봅니다.
- 직접 고른 화질은 그 영상을 보는 동안에만 유지됩니다. 일시정지·되감기 후에도 그대로지만, 다른 영상에 갔다가 뒤로 가기로 돌아오면 다시 최고 화질로 바꿉니다.
- 목표 화질을 고르는 메뉴는 없습니다. 항상 가능한 최고 화질을 고르되, 8K는 버퍼링이 심해 4K까지만 자동으로 고릅니다. 직접 8K를 고르는 것은 막지 않습니다.

## 개발

소스는 `src/features/<기능>/`에 기능별로 있고, 빌드하면 `tubekit.user.js` 한 파일로 합쳐집니다.

```bash
npm ci
npm run build
npm test
```

작업 규칙은 [AGENTS.md](AGENTS.md), 버전별 변경 내용은 [CHANGELOG.md](CHANGELOG.md)에 있습니다.
