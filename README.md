# Tubekit

YouTube를 쓰면서 불편했던 점을 고치는 개인용 유저스크립트입니다.

설치·업데이트 주소:

```text
https://raw.githubusercontent.com/Oince/tubekit/main/tubekit.user.js
```

## 기능

### 오른쪽 댓글 패널

플레이어와 영상 정보의 배치는 그대로 두고, 오른쪽 열을 `댓글 | 관련 동영상` 탭으로 바꿉니다.

- 2열 화면에서는 오른쪽에 `댓글 | 관련 동영상` 탭이 나타납니다.
- 영상에 들어가면 댓글 탭이 먼저 열립니다.
- 관련 영상을 누르거나 앞뒤로 이동하면, YouTube가 새 영상을 보여 줄 때까지 이전 영상의 댓글 패널이 그대로 남아 있다가 새 영상으로 바뀌는 순간 새 영상의 댓글 탭으로 바뀝니다. 이동이 취소되어 같은 영상에 머물면 보던 탭과 스크롤 위치가 그대로 이어집니다. 홈이나 검색으로 나갈 때도 새 화면이 그려질 때까지 댓글 패널이 그대로 남습니다.
- 두 탭은 같은 영상에서 전환하는 동안 각각의 스크롤 위치를 유지합니다.
- 탭에 키보드 포커스를 둔 상태에서 좌우 방향키로 전환하고, Home/End로 첫 번째/마지막 탭을 선택할 수 있습니다.
- 별도의 전환 버튼은 없고 2열 화면에서는 항상 자동으로 적용됩니다.
- 극장 모드, 미니플레이어, 좁은 단일 열 화면처럼 2열 화면이 아니게 되면 그 순간 댓글 패널이 사라지고 YouTube의 원래 레이아웃으로 돌아갑니다. 다시 2열 화면이 되면 곧바로 댓글 패널이 서고, 같은 영상이면 보던 탭이 다시 열립니다.
- 전체화면을 켜면 그동안 댓글 패널을 숨겨 둡니다. 전체화면을 끄면 보던 탭과 스크롤 위치로 돌아옵니다. 그 사이 다른 영상으로 넘어갔거나 끈 뒤의 화면이 2열 화면이 아니면 위처럼 원래 레이아웃으로 돌아갑니다.
- 실시간 채팅(다시보기 포함), 동영상 정보(챕터·스크립트), 질문하기, 상품처럼 YouTube가 오른쪽 열에 패널을 펼치면 그동안 댓글 패널을 숨깁니다. 댓글과 관련 동영상도 함께 숨으며, 패널을 모두 닫으면 보던 탭과 스크롤 위치로 돌아옵니다.
- 펼쳐진 YouTube 패널은 댓글 패널이 있던 자리를 같은 너비·높이로 채우고, 페이지를 스크롤해도 그 자리에 붙어 있습니다. 창이 낮으면 댓글 패널처럼 그 자리에 맞춰 줄어듭니다. 극장 모드·미니플레이어·좁은 화면처럼 2열 화면이 아니면 YouTube 원래 배치 그대로입니다.
- YouTube 패널이 둘 이상 펼쳐지면 그 자리 맨 위에 탭 줄이 생기고, 고른 패널 하나만 남은 자리를 채웁니다. 탭은 YouTube가 위아래로 쌓는 순서대로 놓이고 이름은 각 패널의 제목 그대로입니다(채팅은 채팅 헤더의 제목이라 모드를 바꾸면 따라 바뀝니다). 나머지 패널은 닫지 않고 숨겨 둡니다. 새 패널이 열리거나 이미 열린 패널을 다시 여는 버튼(예: 챕터 "모두 보기", "스크립트 표시")을 누르면 그 탭으로 바로 넘어가고, 보던 패널을 닫으면 직전에 보던 탭(없으면 맨 앞 탭)으로 돌아갑니다. 하나만 남으면 탭 줄이 사라집니다. 탭은 댓글 패널 탭과 같은 방식으로 방향키·Home/End로 고를 수 있습니다.
- 극장 모드 등으로 댓글 패널이 사라졌다가 같은 영상에서 다시 2열 화면이 되면, 보던 YouTube 패널 탭으로 돌아옵니다. 그사이 새 패널을 열었으면 그 패널 탭, 보던 패널을 닫았으면 맨 앞 탭입니다. 다른 영상으로 옮기면 이어지지 않습니다.
- 업로더가 댓글을 끈 영상이나 진행 중인 실시간 방송처럼 댓글이 꺼진 영상에서는 알림을 띄우고 관련 동영상 탭으로 바꿉니다. 방송이 끝난 다시보기는 댓글이 있으므로 채팅을 닫으면 댓글 탭이 보입니다.
- 적용 주소는 `https://www.youtube.com/watch?v=...`입니다. YouTube가 플레이어와 오른쪽 열을 나란히 놓은 화면(2열 화면)이면 동작합니다. 픽셀 기준을 따로 두지 않고 YouTube의 배치를 그대로 따르며, YouTube는 보통 스크롤바를 뺀 페이지 너비가 **1000 CSS px 이상**일 때 2열로 바꿉니다. 그래서 스크롤바가 자리를 차지하는 환경에서는 창 너비 약 1015px부터, 오버레이 스크롤바 환경에서는 1000px부터 적용됩니다. 모니터 해상도와 다르며 브라우저 확대/축소의 영향을 받습니다.
- `m.youtube.com`(모바일 웹), YouTube 앱, 쇼츠 화면에는 적용되지 않습니다.

### 쇼츠를 영상 화면에서 열기

쇼츠 영상을 쇼츠 화면(`/shorts/...`) 대신 영상 화면(`/watch?v=...`)에서 엽니다. 데스크톱(`www.youtube.com`)과 모바일 웹(`m.youtube.com`) 모두에 적용됩니다.

- 쇼츠 화면 주소를 직접 열거나 새 탭에서 열면 바로 영상 화면 주소로 바꿔 엽니다. 시작 시간 등 주소의 다른 값은 유지합니다.
- YouTube 안에서 쇼츠 영상을 클릭하면 새로고침 없이 영상 화면으로 이동합니다. 뒤로 가기를 누르면 원래 페이지로 돌아갑니다.
- 영상 화면이므로 2열 화면에서는 오른쪽 댓글 패널도 적용됩니다.
- 왼쪽 메뉴나 모바일 하단 탭의 `Shorts`처럼 특정 영상 없이 쇼츠 화면에 들어가도 YouTube가 고른 첫 영상을 영상 화면에서 엽니다.

### 최고 화질 자동 선택

- 데스크톱(`www.youtube.com`), 모바일 웹(`m.youtube.com`), 다른 사이트에 넣은 영상(`youtube.com/embed`, `youtube-nocookie.com/embed`)에 적용됩니다.
- 영상이 바뀐 뒤 처음 재생될 때 한 번 바꿉니다. 광고가 끝나 본 영상이 시작될 때도 이때로 봅니다.
- 직접 고른 화질은 그 영상을 보는 동안에만 유지됩니다. 일시정지·되감기 후에도 그대로지만, 다른 영상에 갔다가 뒤로 가기로 돌아오면 다시 최고 화질로 바꿉니다.
- 목표 화질을 고르는 메뉴는 없습니다. 항상 가능한 최고 화질을 고르되, 8K는 버퍼링이 심해 4K까지만 자동으로 고릅니다. 직접 8K를 고르는 것은 막지 않습니다.

### 영상 회전

플레이어에 회전 버튼을 두어 영상을 시계 방향으로 90°씩 돌립니다. 옆으로 누워 올라온 영상을 바로 세워 볼 때 씁니다.

- 버튼은 플레이어 하단 오른쪽 컨트롤의 자막 버튼과 설정 버튼 사이에 있습니다. 누를 때마다 90°씩 돌고, 4번 누르면 원래대로 돌아옵니다.
- 영상만 돌려 줄이지 않습니다. 돌린 영상은 돌린 뒤의 비율로 올라온 영상처럼 다뤄집니다. 가로 영상을 90° 돌리면 플레이어가 진짜 세로 영상을 재생할 때와 똑같이 배치되고, 세로 영상을 돌리면 가로 영상처럼 배치됩니다. 기본·극장 모드·전체화면·미니플레이어 모두 YouTube가 그 비율의 영상에 하는 그대로입니다.
- 2열 화면에서 세로로 돌려 오른쪽 열이 넓어지면 댓글 패널도 그 폭을 따릅니다.
- 같은 영상을 보는 동안에는 일시정지, 되감기, 극장 모드·전체화면·미니플레이어 전환, 화질 변경을 거쳐도 회전이 유지됩니다. 다른 영상으로 넘어가면 원래 방향으로 돌아오고, 뒤로 가기로 돌아와도 원래 방향입니다. 미니플레이어를 펼쳐 돌아가면 회전이 유지되지만, 미니플레이어를 닫으면 보기가 끝난 것으로 보고 같은 영상을 다시 열어도 원래 방향으로 시작합니다.
- 광고는 돌리지 않고, 광고가 나오는 동안에는 버튼을 쓸 수 없습니다. 광고가 끝나면 다시 돌린 상태로 돌아옵니다.
- 영상과 함께 진행 막대에 마우스를 올렸을 때 뜨는 미리보기도 돌립니다. 자막, 컨트롤, 종료 화면은 돌리지 않습니다. 영상이 끝나면 YouTube가 하는 그대로 종료 화면 뒤에 영상을 숨기고, 다시 재생하면 돌린 상태로 돌아옵니다.
- 적용 주소는 `https://www.youtube.com/watch?v=...`입니다. iPad Safari도 이 화면을 받으므로 적용됩니다. `m.youtube.com`(모바일 웹)과 다른 사이트에 넣은 영상(embed)에는 적용되지 않습니다. iPhone Safari의 전체화면은 iOS 기본 플레이어로 넘어가 돌린 화면을 보여 줄 수 없기 때문입니다.

## 개발

소스는 `src/features/<기능>/`에 기능별로 있고, 여러 기능이 함께 쓰는 YouTube 페이지·플레이어 어댑터는 `src/core/youtube.js`에 있습니다. 빌드하면 `tubekit.user.js` 한 파일로 합쳐집니다.

```bash
npm ci
npm run build
npm test
```

작업 규칙은 [AGENTS.md](AGENTS.md), 버전별 변경 내용은 [CHANGELOG.md](CHANGELOG.md)에 있습니다.
