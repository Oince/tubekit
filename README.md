# Tubekit

YouTube를 쓰면서 불편했던 점을 고치는 개인용 유저스크립트입니다.

설치·업데이트 주소:

```text
https://raw.githubusercontent.com/Oince/tubekit/main/tubekit.user.js
```

버전별 변경 내용은 [CHANGELOG.md](CHANGELOG.md)에 있습니다.

## 기능

### 오른쪽 댓글 패널

영상 화면의 오른쪽 열을 `댓글 | 관련 동영상` 탭으로 바꿔, 영상을 보면서 댓글을 읽을 수 있게 합니다.

- 영상을 열면 댓글 탭이 먼저 열리고, 탭마다 스크롤 위치가 따로 유지됩니다.
- 실시간 채팅·챕터·스크립트 같은 YouTube 패널을 열면 그 자리를 대신 채우고, 여럿이면 위에 탭이 생깁니다. 모두 닫으면 보던 탭으로 돌아옵니다.
- 플레이어 옆에 오른쪽 열이 있는 화면(창 너비 약 1000px 이상, iPad는 가로)에서만 동작합니다. 극장 모드·전체화면·미니플레이어에서는 YouTube 원래 화면 그대로입니다.
- 모바일 웹(`m.youtube.com`)에는 적용되지 않습니다.

### 쇼츠를 영상 화면에서 열기

쇼츠 영상을 쇼츠 화면(`/shorts/...`) 대신 영상 화면(`/watch?v=...`)에서 엽니다.

- 쇼츠 주소를 직접 열든, YouTube 안에서 쇼츠를 누르든, 메뉴의 `Shorts`로 들어가든 영상 화면에서 열립니다.
- 데스크톱과 모바일 웹(`m.youtube.com`) 모두 적용됩니다.

### 최고 화질 자동 선택

영상을 틀면 가능한 가장 높은 화질로 바꿉니다.

- 4K까지만 자동으로 고릅니다. 8K는 직접 고를 수 있습니다.
- 직접 고른 화질은 그 영상을 보는 동안만 유지됩니다.
- 데스크톱, 모바일 웹, 다른 사이트에 넣은 영상 모두 적용됩니다.

### 영상 회전

플레이어 하단 오른쪽(자막 버튼과 설정 버튼 사이)의 회전 버튼으로 영상을 시계 방향으로 90°씩 돌립니다. 옆으로 누워 올라온 영상을 세워 볼 때 씁니다.

- 돌린 영상은 처음부터 그 방향으로 올라온 영상처럼 플레이어에 맞춰집니다.
- 회전은 그 영상을 보는 동안만 유지되고, 다른 영상으로 넘어가면 원래 방향으로 돌아옵니다.
- 광고 중에는 쓸 수 없습니다.
- 데스크톱과 iPad에서 동작하고, 모바일 웹과 다른 사이트에 넣은 영상에는 적용되지 않습니다.
